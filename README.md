# 🎓 Códigos - Análise e Desenvolvimento de Sistemas (ADS)

Bem-vindo ao meu repositório acadêmico! Este espaço é dedicado a documentar minha jornada e evolução no curso de **Análise e Desenvolvimento de Sistemas** no Centro Universitário Senac.

Aqui você encontrará os exercícios, projetos e implementações práticas desenvolvidas ao longo dos semestres, aplicando conceitos de lógica de programação, estrutura de dados e desenvolvimento de software.

## 🚀 Tecnologias e Linguagens
As principais ferramentas e linguagens exploradas neste repositório incluem:
* **Python** (Lógica de programação, automações e tratamento de dados)
* **Java** (Programação Orientada a Objetos e estruturas de dados)
